Harness CI/CD Proof of Concept

Interactive demonstration of GitHub Integration & Pipeline automation

Harness Live POC Version 1.0

POC Walkthrough Checklist

1
Set Up Harness Trial Active

Created the free trial account on Harness.io platform for experimenting with pipeline steps.

2
Create GitHub Connector

Go to Settings → Connectors → New Connector → GitHub in Harness. Authenticate with a GitHub Personal Access Token (PAT) with repo and admin:repo_hook scopes.

3
Define Codebase Files

Implemented a minimal app with main.py, Dockerfile, requirements.txt, and the Harness pipeline specification inside .harness/pipeline.yaml.

4
Create Webhook Trigger

Create a Webhook trigger inside the Harness pipeline settings, which generates a webhook URL. Paste this webhook URL in the GitHub repository's Settings → Webhooks.

5
Trigger Pipeline Execution

Pushing local commits to the main branch will trigger the pipeline automatically via the webhook. You can simulate it on the right console!

Codebase Files Configuration 

pipeline:
  name: Test Harness CI
  identifier: test_harness_ci
  projectIdentifier: default
  orgIdentifier: default
  tags: {}
  stages:
    - stage:
        name: Build
        identifier: build
        description: ""
        type: CI
        spec:
          cloneCodebase: true
          platform:
            os: Linux
            arch: Amd64
          runtime:
            type: Cloud
            spec: {}
          steps:
            - step:
                type: Run
                name: Test Step
                identifier: test
                spec:
                  shell: Bash
                  command: echo "Testing Harness with GitHub"
            - step:
                type: Run
                name: Build
                identifier: build
                spec:
                  shell: Bash
                  command: |
                    python --version
                    echo "App would be built here"
  properties:
    ci:
      codebase:
        connectorRef: github_connector_poc
        repoName: Harness
        branch: main
FROM python:3.11-slim
COPY . /app
WORKDIR /app
CMD ["python", "main.py"]
print("Hello from Harness!")
